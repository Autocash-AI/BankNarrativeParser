HOW TO USE
==========

Once the package is installed, you can use it in any Python script:

    from banknarrativeparser import BankNarrativeParser

    parser = BankNarrativeParser()
    narrative = "WIRE TRANSFER FROM GOOGLE INC"
    result = parser.get_counterparties(narrative, amount=100.00)

    # Access the extracted data
    print(result['payer']) 
    # Output: GOOGLE INC


HOW TO PUBLISH TO PYPI
======================

PREREQUISITES
-------------
1. Create an account on pypi.org.
2. Authenticate with 2FA (required by PyPI).
3. Go to Account Settings -> API Tokens -> Add API Token.
   - Scope: "Entire account" (or specific project if existing).
   - Copy the token (starts with pypi-). Save it!
4. Install the publishing tools:
   pip install --upgrade build twine

STEP A: BUILD
-------------
Run this command in the project root to create the package files:
    
    python3 -m build

(You will see a 'dist' folder created).

STEP B: UPLOAD
--------------
Run this command to upload to the real PyPI:

    twine upload dist/*

When prompted for credentials:
- Username: __token__
- Password: [Paste your pypi- token here]

That's it! The package will then be live and can be installed by anyone using:
    pip install banknarrativeparser
